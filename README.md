# todoProject

A to-do list that runs in the terminal.

Add tasks, mark them done, delete them, and the list is saved to a file
so it is still there next time.

Built while learning Python — no AI in this project.

## What it uses

- Python 3 only, no external libraries
- JSON to save the list to a file

## How to run it

```bash
python3 todo.py
```
